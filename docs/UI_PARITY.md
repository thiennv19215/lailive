## Current mismatch ledger

- Copy: core Vietnamese labels match the observed skeleton; account names and project names are intentionally anonymized.
- Layout: the Home/Projects screen now intentionally prioritizes usability over the earlier measured clone geometry: a descriptive heading, primary `Tạo dự án mới` action, project readiness cues, visible `Tiếp tục` actions, and a compact overflow menu replace the engineering-dashboard presentation. Editor widths/heights continue to follow the current reference ledger.
- Typography: the reference-confirmed Projects and Settings shells now load bundled Inter instead of depending on a missing system font. Other screens retain their accepted fallback until screen-specific evidence shows that changing them improves parity.
- Palette: root `#0b0b0d` and titlebar `#131316` match observed reference computed values; remaining panel/accent/overlay samples are still incomplete.
- Assets: all rebuild imagery is independent; reference branding/posters are not copied.
- Behavior: route selection, tool/category tabs, background empty state, layer add/delete, export/start safety dialogs, livestream form editing, and mock save feedback work; backend workflows remain phase-scoped.
- Security deviation: reference cookie forms are represented for workflow parity, but the rebuild explicitly accepts only disposable demo JSON in Phase 1 and clears it without persistence or network transmission.
- Project/template dialogs are deliberately replaceable assumptions until they can be observed without changing authenticated reference data.
- Registration uses independent decorative geometry and a local-only success notice; form structure and observed validation copy match, while real service submission remains outside the safe Phase 1 audit.
- Screenshot evidence: the comparison harness is verified with synthetic changed-pixel tests and an identity CLI proof; same-viewport reference/rebuild captures remain required before mismatch percentages enter this ledger.
- Capture integrity: desktop login/projects/templates/editor rebuild artifacts are now true PNG files generated through isolated Electron capture. The older mobile project JPEG remains excluded until recaptured through the same runner.
- Quantitative priority: templates (45.3324%) remains the largest measured desktop mismatch, followed by projects (16.3270%), editor (12.6332%), login (5.6526%), and settings (3.6747%). Template improved 7.4855 percentage points, projects improved 8.8458, editor improved 10.6777, login improved 26.8391, and the accepted Settings iteration improved another 1.4062 points after bundling Inter. Independent artwork dominates the remaining template/project/editor mismatch, while fine typography and shape offsets dominate login/settings.
- Mobile accessibility deviation: reference auth pages preserve a desktop hero and make their forms unreachable at 390x844. The rebuild hides the oversized hero content and prioritizes the complete form; this deliberate behavior difference must not be counted as an accidental parity regression.
